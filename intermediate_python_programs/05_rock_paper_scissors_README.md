# Rock Paper Scissors

## 📌 Project Overview

An interactive command-line Rock Paper Scissors game where the player competes against the computer.

The computer randomly selects rock, paper, or scissors. The program determines the winner of each round, tracks scores, and displays the final result when the player quits.

## ✨ Features

- Allows the player to choose rock, paper, or scissors.
- Generates random choices for the computer.
- Determines the winner of each round.
- Handles ties.
- Validates player input.
- Tracks player wins, computer wins, and ties.
- Displays the updated score after every round.
- Shows the final score and overall result.
- Allows the player to quit whenever they want.

## 🧠 Concepts Practiced

- Python functions
- `random` module
- Lists and dictionaries
- Constants
- Conditional statements
- Infinite `while` loops
- User input and string methods
- Input validation
- Score tracking using variables
- Returning values from functions

## ▶️ How to Run

Open a terminal in the repository directory and execute:

```bash
python intermediate_python_programs/05_rock_paper_scissors.py
```
