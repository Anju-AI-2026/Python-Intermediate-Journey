# Intermediate Python Programs

A collection of practical Python programs designed to strengthen programming logic and explore intermediate-level concepts through simple, interactive examples.

## Programs

1. Number Guessing Game
2. Password Generator
3. Age Calculator
4. Text File Word Counter
5. Rock Paper Scissors
6. Simple Banking System
7. To-Do List with File Storage
8. Quiz Application

## Concepts Practiced

- Functions and modular programming
- Loops and conditional statements
- Random number generation
- Input validation and exception handling
- Strings and date calculations
- Dictionaries and data structures
- File handling and data persistence
- Interactive program design

## Technologies Used

- Python 3
- Python standard library

## Purpose

To improve problem-solving skills, write cleaner code, and build a collection of small, practical Python programs suitable for continued learning and GitHub practice.
