# Lambda Functions in Python

This folder contains Python programs demonstrating the use of **lambda functions** and how they can be used to write short, anonymous functions.

## 📌 About

Lambda functions are small functions defined using the `lambda` keyword. Unlike regular functions, they can contain only a single expression and do not require a function name.

## 📂 Programs

| File | Description |
|---|---|
| `01_lambda_basics.py` | Introduces lambda functions and demonstrates how to create and use simple anonymous functions. |
| `02_lambda_conditions.py` | Demonstrates how conditional expressions can be used inside lambda functions. |

## 🧠 Concepts Covered

- Lambda function syntax
- Anonymous functions
- Function arguments and return values
- Conditional expressions
- Using lambda for short operations

## ▶️ How to Run

Make sure Python is installed on your system.

Run individual programs from the repository root:

```bash
python 06_Lambda/01_lambda_basics.py
python 06_Lambda/02_lambda_conditions.py
```

## 🎯 Learning Objective

The purpose of this collection is to understand lambda function syntax and learn when short anonymous functions can be useful in Python.
