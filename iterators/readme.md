# Python Iterators

A collection of practical Python programs exploring iterables, iterators, and sequential data processing.

## Programs

1. **Manual Iterator** – Creating and using iterators with `iter()` and `next()`.
2. **Inventory Iterator** – Processing structured inventory data using iterators.
3. **Batch Processor** – Processing data in smaller batches and exploring generator concepts.

## Topics Covered

- Manual iteration using `iter()` and `next()`
- Handling iterator exhaustion with `StopIteration`
- Processing structured data with iterators
- Sequential data processing
- Batch processing
- Introduction to generators

## Technologies Used

- Python 3
- Python built-in functions and standard features

## Purpose

To understand how Python iterators work, practice sequential data access, and develop a foundation for efficient data processing using iterators and generators.
