# Python Comprehensions

This folder contains Python programs demonstrating comprehensions, a concise way to create new collections from existing iterables.

## 📂 Programs

| File | Description |
|---|---|
| `01_comprehension_basics.py` | Introduction to Python comprehensions. |
| `02_comprehension_conditions.py` | Using conditions within comprehensions. |
| `03_comprehension_project.py` | Applying comprehension concepts in a practical project. |
| `04_comprehension_advanced.py` | Exploring advanced comprehension techniques. |
| `05_comprehension_challenges.py` | Practicing comprehension concepts through challenges. |

## 🧠 Concepts Covered

- List comprehensions
- Conditional comprehensions
- Creating collections using concise expressions
- Practical applications of comprehensions
- Advanced comprehension techniques

## ▶️ How to Run

Run a program from the repository root:

```bash
python Comprehension/01_comprehension_basics.py
```

Replace the filename to run another program.

## 🎯 Learning Objective

Understand how comprehensions make Python code more concise, readable, and efficient when creating collections.
