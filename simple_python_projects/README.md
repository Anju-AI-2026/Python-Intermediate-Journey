# Simple Python Projects

A collection of small, practical Python programs designed to
strengthen programming logic and improve problem-solving skills.

## Programs

1. ATM PIN Simulator
2. Number System Converter
3. Electricity Bill Calculator
4. Shopping Bill Generator
5. Seat Reservation Simulator
6. Rock-Paper-Scissors Tournament
7. Daily Habit Tracker
8. Random Team Generator

## Concepts Practiced

- Functions and modular programming
- Conditional statements and loops
- Lists and dictionaries
- Input validation
- Mathematical calculations
- String manipulation
- Random number generation
- Basic data management

## Technologies Used

- Python 3
- Python standard library

## Purpose

To practise Python through simple, interactive programs
while gradually improving coding skills and logical thinking.
