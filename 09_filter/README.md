# Filter Function in Python

This folder contains Python programs demonstrating the use of the built-in `filter()` function to select elements from iterables based on specific conditions.

## 📌 About

The `filter()` function is used to extract elements from an iterable that satisfy a given condition.

It takes a function and an iterable as arguments and returns a filter iterator containing only the elements for which the function returns `True`.

## 📂 Programs

| File | Description |
|---|---|
| `01_filter_basics.py` | Introduces the `filter()` function and demonstrates filtering elements from an iterable. |
| `02_filter_conditions.py` | Demonstrates using conditions to filter elements based on specific requirements. |
| `03_filter_lambda.py` | Demonstrates combining `filter()` with lambda functions for concise filtering operations. |

## 🧠 Concepts Covered

- Python's built-in `filter()` function
- Iterables and iterators
- Boolean conditions
- Lambda functions
- Filtering data
- Converting filter objects into lists

## ▶️ How to Run

Make sure Python is installed on your system.

Run individual programs from the repository root:

```bash
python 09_filter/01_filter_basics.py
python 09_filter/02_filter_conditions.py
python 09_filter/03_filter_lambda.py
```

## 🎯 Learning Objective

The purpose of this collection is to understand how `filter()` works and how it can be combined with conditional expressions and lambda functions to select specific elements from data collections.
