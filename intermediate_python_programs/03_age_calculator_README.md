# Age Calculator

## 📌 Project Overview

A Python program that calculates a person's exact age in years, months, and days using their date of birth and the current date.

It uses Python's built-in date and calendar modules to handle different month lengths and date calculations.

## ✨ Features

- Accepts birth year, month, and day from the user.
- Calculates age using the current date.
- Displays age in years, months, and days.
- Handles months with different numbers of days.
- Accounts for leap years through calendar calculations.
- Prevents future birth dates.
- Validates date input and handles invalid values.
