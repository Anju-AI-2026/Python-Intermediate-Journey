# Python `zip()` Function

This folder contains Python examples demonstrating the built-in `zip()` function. The `zip()` function combines elements from two or more iterables based on their positions.

## 📂 Programs

| File | Description |
|---|---|
| `01_zip_basics.py` | Introduction to the `zip()` function and combining multiple iterables. |
| `02_zip_conditions.py` | Using `zip()` with conditional logic. |
| `03_zip_advanced.py` | Exploring more advanced applications of `zip()`. |

## 🧠 Concepts Covered

- Python's built-in `zip()` function
- Combining multiple lists and iterables
- Accessing paired elements
- Using `zip()` with conditional statements
- Practical applications of iterable pairing

## ▶️ How to Run

Run any program from the repository's root directory:

```bash
python 10_zip/01_zip_basics.py
```

Replace the filename to execute another example.

## 🎯 Learning Objective

Understand how Python's `zip()` function works and how it can simplify operations involving multiple iterables.
