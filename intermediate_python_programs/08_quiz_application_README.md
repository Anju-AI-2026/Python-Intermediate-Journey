# Quiz Application

## 📌 Project Overview

An interactive command-line Python quiz application that tests users on basic and intermediate Python concepts.

The quiz contains multiple-choice questions with four options. It validates answers, calculates the final score, and displays performance feedback based on the user's percentage.

## ✨ Features

- Contains 8 multiple-choice Python questions.
- Displays four options for every question.
- Accepts answers using A, B, C, or D.
- Validates user input.
- Provides immediate feedback for correct and incorrect answers.
- Displays the correct answer when a response is incorrect.
- Tracks the user's score.
- Calculates the final percentage.
- Displays the number of correct and incorrect answers.
- Provides performance feedback based on the final score.
