# Map Function in Python

This folder contains Python programs demonstrating the use of the built-in `map()` function to apply operations to elements in an iterable.

## 📌 About

The `map()` function applies a given function to every item in an iterable, such as a list or tuple, and returns a map iterator containing the results.

It is useful for transforming collections of data without writing explicit loops.

## 📂 Programs

| File | Description |
|---|---|
| `01_map_basics.py` | Introduces the `map()` function and demonstrates applying a function to iterable elements. |
| `02_map_lambda.py` | Demonstrates combining `map()` with lambda functions for concise data transformations. |

## 🧠 Concepts Covered

- Python's built-in `map()` function
- Iterables and iterators
- Function arguments
- Lambda functions
- Data transformation
- Converting map objects into lists

## ▶️ How to Run

Make sure Python is installed on your system.

Run individual programs from the repository root:

```bash
python 07_Map/01_map_basics.py
python 07_Map/02_map_lambda.py
```

## 🎯 Learning Objective

The purpose of this collection is to understand how `map()` works and how it can be combined with regular and lambda functions to transform iterable data efficiently.
