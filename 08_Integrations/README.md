# Python Data Integration Projects

This folder contains Python programs that work with different types of structured data and demonstrate how multiple data-processing operations can be combined to solve practical problems.

## 📌 About

These projects focus on transforming, analyzing, organizing, and managing data using Python.

They cover practical examples involving playlists, expenses, student records, contacts, inventory, payroll, library books, attendance, and movie ratings.

## 📂 Programs

| File | Description |
|---|---|
| `01_playlist_transformer.py` | Demonstrates transforming and organizing playlist data. |
| `02_expense_analyzer.py` | Analyzes expense records and performs expense-related calculations. |
| `03_student_score_analyzer.py` | Processes student scores and performs basic score analysis. |
| `04_expense_category_analyzer.py` | Organizes and analyzes expenses based on their categories. |
| `05_contact_data_transformer.py` | Demonstrates transforming and organizing contact information. |
| `06_product_inventory_analyzer.py` | Processes product inventory data and performs inventory-related analysis. |
| `07_employee_payroll_analyzer.py` | Works with employee payroll information and salary calculations. |
| `08_library_book_tracker.py` | Demonstrates organizing and tracking library book information. |
| `09_student_attendance_tracker.py` | Manages and tracks student attendance records. |
| `10_movie_rating_analyzer.py` | Processes movie ratings and performs rating-related analysis. |

## 🧠 Concepts Covered

- Working with structured data
- Data transformation and organization
- Lists and dictionaries
- Data filtering and aggregation
- Conditional logic
- Loops and functions
- Numerical calculations
- Practical data management

## ▶️ How to Run

Make sure Python is installed on your system.

Run an individual program from the repository root using:

```bash
python 08_Integrations/01_playlist_transformer.py
```

Replace the filename with the program you want to execute.

The purpose of this collection is to practise applying Python programming concepts to practical data-processing and data-management tasks.
